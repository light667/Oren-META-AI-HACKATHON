# Relais LLM Mistral + Gemini derrière Meta (2026-11-04)

Contexte : la clé Meta Model API peut s'épuiser (crédit/quota). L'app ne dépend que de l'interface `LlmProvider` ([types.ts](/src/providers/llm/types.ts)) ; `createLlmProvider()` ([index.ts](/src/providers/llm/index.ts)) construit désormais une chaîne Meta → Mistral → Gemini ([fallback.ts](/src/providers/llm/fallback.ts)) : chaque appel essaie le fournisseur suivant si le précédent échoue (clé absente, 401/402/429/5xx, réseau) ou n'est pas adapté (Meta refuse un audio non-WAV ou un `tool_choice` forcé, Mistral/Gemini les acceptent ; Meta reste principal pour le hackathon).
Mistral ([mistral.ts](/src/providers/llm/mistral.ts)) : chat OpenAI-compatible (outils, JSON schéma, vision), transcription Voxtral `POST /v1/audio/transcriptions` (wav/mp3/m4a/ogg). Modèle par défaut `ministral-8b-latest` : vérifié en réel, Large renvoie 403 et Small/Medium 429 sur le palier de la clé actuelle ; surcharge par `MISTRAL_CHAT_MODEL`.
Gemini ([gemini.ts](/src/providers/llm/gemini.ts)) : `generateContent` (outils `functionDeclarations`, vision, JSON, transcription audio multimodale), auth par en-tête `x-goog-api-key`, modèle `gemini-2.5-flash` (`GEMINI_MODEL`).
Clés : variables d'environnement uniquement (`MISTRAL_API_KEY`, `GEMINI_API_KEY` dans `.env` local ignoré par git et `.env.example` sans valeurs) — aucun secret dans le code, conformément à AGENTS.md. Pour la production, ajouter les deux clés (et `MISTRAL_CHAT_MODEL=ministral-8b-latest`) dans Vercel > Settings > Environment Variables, sinon le relais n'existera qu'en local.
Vérifié en réel (un appel minimal par fournisseur) : Mistral chat « OK », appel d'outil correct, transcription Voxtral de `test/voix.wav` correcte (« Bonjour, nous sommes ouverts… »). Gemini : première clé = projet Google suspendu ; seconde clé (2026-11-04) = authentification acceptée mais « free tier is not available for this project » (403 PERMISSION_DENIED) — ce projet exige la facturation activée (ou une clé créée dans un projet éligible au palier gratuit AI Studio). En attendant la chaîne le saute automatiquement et Mistral assure le relais. Tests : `npm test` (dont [fallback.test.ts](/src/providers/llm/fallback.test.ts), 9 tests : bascule 429, bascule format audio, échec total explicite), build et typecheck à relancer après déploiement des variables Vercel.
Sécurité : les clés ont été transmises en clair dans la conversation — les régénérer après le hackathon (Mistral Console, Google AI Studio) et ne jamais les coller dans un dépôt, même privé.
